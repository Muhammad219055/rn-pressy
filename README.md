# react-native-btn

A fun, cross-platform React Native button with customizable styles, haptic feedback, and smooth press effects.

## Installation


```sh
npm install react-native-btn
```


## Usage


```js
import { multiply } from 'react-native-btn';

// ...

const result = await multiply(3, 7);
```
